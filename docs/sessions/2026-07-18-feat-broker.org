* Decisions Made
- *Broker mirrors ADR-0013's shape, scoped to LSP sessions* (no ns/cgroup
  placement, no privilege drop — a workstation session cache, not a security
  ring). Same primitives: path-based unix sockets only (abstract rejected),
  broker owns stale-socket cleanup on (re)bind, jsonrpc over the unix conn.
- *Servers launch on the broker's LIFETIME context*, never a request context —
  =exec.CommandContext= binds process lifetime to its context, so a single
  cancelled request must not reap the warm subprocess. Request ctx is used only
  for the forwarded LSP Call.
- *Single-flight via a per-session =ready= channel*: the first ensureSession
  inserts a placeholder + spawns; concurrent callers for the same key block on
  =ready=. srv/initErr published before =close(ready)=. Failed cold start drops
  the placeholder so a later call retries.
- *Idle-reap is clock-injectable* (=Config.Clock=): =reapIdle(now)= is unit-
  tested deterministically; the reaper goroutine (started by =Serve=) calls it
  with =b.now()=. In-flight guard (=inflight= counter) prevents reap mid-query.
- *WorkspaceEdit.UnmarshalJSON normalizes both wire forms.* Verified pyright
  1.1.411 returns =documentChanges= for rename EVEN without the client
  advertising it; folding documentChanges→Changes keeps the write path uniform
  (=wsedit.FromWorkspaceEdit= reads one map).
- *stdlib =flag=, NOT pflag, for the daemon.* The global Go rule prefers pflag,
  but adding it would create a =go.sum= and break the zero-external-dependency
  keystone invariant the task explicitly reaffirmed. Specific constraint wins;
  noted in README + daemon doc-comment. (CLAUDE.md › Rule Preservation §3.)
- *mgmt 4c5b4838*: only =schema= takes a json tag; Files/Path/Edits/Start/End/
  NewText keep Go-default capitalized keys — the exact shape ae's
  =wseditingest.ParsePlan= already decodes (locked by a wire-shape test).
